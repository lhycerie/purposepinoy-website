# Purpose Pinoy Organization 🇵🇭

This project is a youth-driven web platform made by the Purpose Pinoy IT Committee dedicated to empowering Filipinos through entrepreneurship, innovation, and community-led initiatives. 

Live Website: https://purposepinoy.org

## 📌 About the Project
The website was created to support the organization’s mission of breaking the cycle of poverty through youth leadership and enterprise. 

The platform showcases:

- Community outreach programs
- Volunteer initiatives
- Partnerships and fundraising campaigns
- Organizational mission and impact metrics

## ⚙️ Technologies
- `HTML`
- `Tailwind CSS`
- `Javascript`
- `Alpine JS`
